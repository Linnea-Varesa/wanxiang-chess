# 三个月无视觉验收清单（当前 3×3 路线）

时间 tag：2026-09-22

## 10 月识别和定位

- [ ] 第一批完整 3×3 九线圈物料已到货、拍照、核对型号和缺件。
- [ ] 兵、马、车各有至少一枚 3D 打印样品，底部可安装标签和磁铁。
- [ ] PN5180 能稳定读取至少 3 枚不同 ISO15693 标签 UID。
- [ ] 1 个读头通过 RF 切换逐格连接 3 个线圈，线圈编号与 UID 对应。
- [ ] 3～4 个霍尔与磁铁能区分至少 3 个格子的有/无棋子状态。
- [ ] 九路线圈静态快照可重复采集，记录成功率、空读、串读和扫描耗时。
- [ ] 错误状态保留为 `EMPTY`、`IDENTITY_READ_FAIL`、`GHOST_READ` 或 `UNSTABLE`，不得沿用旧 UID。

## 11 月识别收尾

- [ ] 完成供电、接地、RF匹配、继电器切换时序和重试策略。
- [ ] 固化 UID 登记表、格位映射、快照协议和屏幕状态。
- [ ] 连续扫描、断电重启、拔插和错放测试可复现。

## 12 月软件协同

- [ ] Android 或电脑调试端能接收完整快照并显示棋盘。
- [ ] AI 返回合法走法并支持至少 3 档难度。
- [ ] AI 指定走法后，玩家手动放置，系统用 UID 和格位复核。
- [ ] BLE 断线后重连请求完整快照。

自动移子、8×8 全盘、量产 PCB 和多棋子同步不属于本阶段验收。
