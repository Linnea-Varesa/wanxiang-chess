# 三个月无视觉验收清单

## 设备和身份

- [ ] ESP32-S3 上电后 10 秒内进入可连接状态。
- [ ] 3–5 枚 DS2431G/GA 棋子可逐枚读取 ROM UID，并完成至少一枚 EEPROM 写入/读回；DS2401 备件只用于电气测试。
- [ ] 2×2 触点阵列在旋转、轻微偏心、抬起和放下后仍能读到正确 UID。
- [ ] 4×4 扫描能区分空格和 UID，单次稳定扫描不超过 2 秒。
- [ ] 读不到、两个格同时变化、触点抖动时进入 `UNSTABLE`，不自动猜测。

## 对局和 APP

- [ ] Android 能通过 BLE 连接并显示设备状态。
- [ ] APP 能显示 UID 对应的颜色、角色和格位。
- [ ] AI 能在手机本地返回合法走法，并至少提供 3 档难度。
- [ ] 语音能说清“颜色、棋子、源格、目标格”。
- [ ] AI 指定 `e2-e4` 后，系统只有在同一 UID 从 e2 到 e4 时才确认。
- [ ] 玩家走一步后，APP 能进行合法性判断并请求 AI 下一步。
- [ ] BLE 断开后，重连先请求完整快照，不重复提交上一事件。

## 演示

- [ ] 从初始局面开始连续完成至少 10 步人工移子。
- [ ] 演示一次放错棋子或放错格，APP 给出可理解的错误提示。
- [ ] 演示材料明确说明自动移子、64 格扩展和量产不属于本版本。
- [ ] 保留一份接线图、UID 注册表、测试数据和 3 分钟演示脚本。
