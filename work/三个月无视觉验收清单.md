# 三个月无视觉验收清单

## 设备和身份（2026-09-18 路线更新）

- [ ] ESP32-S3 上电后 10 秒内进入可连接状态。
- [ ] 兵、马、车各有至少一枚 3D 打印样品，底部可安装可拆身份盘。
- [ ] 至少一种 NTAG213 小标签在约 3 mm 非金属板下可重复读取 UID。
- [ ] 2×2 无触点样片能区分四个格，记录相邻格串读和读距。
- [ ] 玩家手动移动一枚棋子后，系统能复核 UID 和目标格；读数不稳时进入 `UNSTABLE`/`PAUSED`。
- [ ] DS2431/DS2401 触点方案只作为回退实验，不作为自行移动主线验收。

## 对局和 APP

- [ ] 前端调试端能通过 BLE 或串口连接并显示设备状态；Android/微信小程序不在本阶段绑定。
- [ ] APP 能显示 UID 对应的颜色、角色和格位。
- [ ] AI 能在手机本地返回合法走法，并至少提供 3 档难度。
- [ ] 语音能说清“颜色、棋子、源格、目标格”。
- [ ] AI 指定 `e2-e4` 后，系统只有在同一 UID 从 e2 到 e4 时才确认。
- [ ] 玩家走一步后，APP 能进行合法性判断并请求 AI 下一步。
- [ ] BLE 断开后，重连先请求完整快照，不重复提交上一事件。

## 演示

- [ ] 从初始局面开始连续完成至少 10 步人工移子。
- [ ] 演示一次放错棋子或放错格，APP 给出可理解的错误提示。
- [ ] 演示材料明确说明 8×8 全盘、多棋子同步和量产不属于本版本。
- [ ] 保留一份接线图、UID 注册表、测试数据和 3 分钟演示脚本。
