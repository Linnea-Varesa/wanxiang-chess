# 阶段 3D 可视化

本目录保存不依赖构建工具的阶段演示页面，用于向老师和组员直观看到每个阶段要达到的目标效果。

- `阶段进度3D展示.html`：离线打开即可使用的 CSS 3D 原型；点击阶段按钮或播放按钮切换场景。
- 页面中的棋子、读头、位置层、后续运动接口和屏幕是示意模型，不代表已经完成的实物；真实尺寸、读距和扫描误差以 `F:/projects/wanxiang-chess/experiments/` 下的实测记录为准。
