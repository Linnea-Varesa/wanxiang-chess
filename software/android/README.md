# Android 首版

首版屏幕流程：扫描设备 → 连接 → 请求完整快照 → 显示棋盘 → 等待玩家 → 显示/播报 AI 走法 → 等待实体落子确认 → 更新记录。

最小功能：BLE 连接、8×8 棋盘、同步状态、难度设置、语音开关、FEN/PGN 本地记录、错误和重新同步。暂不做账号、云端、远程联机和复杂聊天。

无视觉版本的连接流程：

1. 扫描并连接 ESP32-S3 自定义 GATT 服务。
2. 发送 `SNAPSHOT?`，接收 `IDSCAN` 记录并用通道映射表换算格位。
3. 首次使用进入“棋子登记”：逐枚把 DS2431/DS2401 棋子放在登记位，读取 UID；DS2431 可在独立写入夹具中预写初始信息，再由 APP 建立绑定。
4. AI 走法进入 `WAIT_CONFIRM` 后，只有同一 UID 从源格到目标格才推进逻辑局面。

Android 12 及以上需要在运行时申请 `BLUETOOTH_SCAN` 和 `BLUETOOTH_CONNECT`；不做账号和云端登录。Stockfish 作为本地 UCI 引擎，先限制搜索深度和思考时间，避免把手机性能当成硬件识别的前置条件。
