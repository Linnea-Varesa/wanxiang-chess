# DS2431 身份写入工具

## 用途

此目录保存独立的 DS2431G/GA 登记、EEPROM 写入、读回校验和 UID 导出工具。它服务于棋子装配前的单枚芯片处理，不参与棋盘 2×2/4×4/8×8 的在线扫描。

## 当前状态

- 目录和功能边界已建立；
- 尚未编写真实写入驱动；
- 在接触座、芯片样品和强上拉电路到位前，只允许实现 `READ_ROM` 原型；
- 首次写入必须保留原始 UID、输入字段、读回字段、时间和失败原因。

## 写入边界

写入工具必须使用独立接触座和强上拉；禁止在多路器扫描总线上对棋子执行 EEPROM 写入。写后整页读回失败时，芯片标记为不可装配，不能只依据一次“写入命令返回成功”。
