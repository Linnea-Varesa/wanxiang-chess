# 教师汇报与阶段计划

本目录保存面向指导老师的项目阶段汇报、采购判定、分工和周任务。所有文件名和文档标题都带有时间范围或时间 tag，便于按周归档。

## 文件说明

- `00_阶段汇报_2026-09-18.md`：当前项目状态、方向、预计方案、采购和年底目标总览。
- `01_项目方向与预计方案.md`：技术路线、系统边界、首版与后续版本的关系。
- `02_采购物资与核验.md`：首批采购清单、参数核验、采购顺序和暂缓物资。
- `03_分工与接口.md`：两人分工、每周投入、交付物和共同验收规则。
- `04_月度里程碑_2026-09-19_2026-12-31.md`：按月份的目标、产出和退出条件。
- `05_周任务计划_2026-09-19_2026-12-31.md`：从明天开始到 12 月底的具体周任务；每周二是总结节点。
- `06_周总结模板.md`：每周二复制使用的汇报模板。

## 当前资料边界

本目录是汇报视图，不替代工程文档。技术细节以根目录 `docs/`、`hardware/`、`firmware/`、`software/` 和 `experiments/` 为准。历史交接文件和演示工程只作参考。

## 时间规则

- 项目排期起点：`2026-09-19`。
- 每周总结节点：星期二。
- 首次总结：`2026-09-22`，覆盖启动后的首个短周期。
- 常规周期：星期三至下周二。
- 年底收口：`2026-12-31`。
- 计划产能：两人各 6 小时/周，合计约 12 人时/周；采购等待和返工不计作已完成产出。
