# 2×2 一线制身份识别实验

## 目的

验证 ESP32-S3 能否通过 74HC4067 逐格读取 DS2431G/GA（或 DS2401+ 备件）的 64-bit UID，并在棋子旋转、轻微偏心和抬起/放下时稳定区分 `EMPTY` 与具体棋子。EEPROM 写入另做夹具实验，不在 2×2 扫描时写入。

## 接线

- ESP32-S3 GPIO5：1-Wire DQ，外接 4.7 kΩ 上拉到 3.3 V；DS2431 写入时另加可控强上拉，不与普通扫描共用未经验证的电源路径。
- GPIO6–9：74HC4067 的 S0–S3。
- GPIO10：74HC4067 的 EN，低有效。
- 74HC4067 的 SIG：1-Wire DQ。
- 每个实验格的两触点：一端接 SIG 选路，另一端接 GND；棋子底部 DS2431 的 IO/GND 或 DS2401 的 DQ/GND 触点对应连接。
- 未使用通道保持空，不要悬空接入金属片。

## 测试步骤

1. 不放棋子，连续执行 `ID_SCAN` 20 次，16 个通道应全部为 `EMPTY`。
2. 在通道 0 放棋子 A，记录 UID，旋转 0°、90°、180°、270° 各扫描 20 次。
3. 将棋子偏离中心 1 mm、2 mm、3 mm，记录漏读次数。
4. 在通道 1 放棋子 B，同时扫描通道 0 和 1，检查是否串读；记录 family code `0x2D`（DS2431）或 `0x01`（DS2401 备件）。
5. 先抬起 A，再放回通道 1，确认软件能看到 `EMPTY → UID_A`，而不是把 UID_A 留在通道 0。
6. 通过 BLE 和串口各执行一次，比较消息内容一致性。

## 记录字段

`日期,芯片UID,通道,旋转角度,偏心量,扫描次数,成功次数,CRC错误,空读,平均扫描周期_ms,备注`

## 通过条件

- 单枚棋子 100 次扫描成功率 ≥ 98%。
- 两个相邻通道没有把 UID 读到错误格位。
- 从抬起到放回的状态变化能在 2 秒内完成。
- CRC 错误和接触不稳必须进入 `UNSTABLE`，不能被当作合法落子。

若 2×2 不通过，先改触点和机械定位；不要通过增加芯片数量或购买 64 个读头掩盖问题。
