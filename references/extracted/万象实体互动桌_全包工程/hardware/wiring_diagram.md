  │ LM2596  │                       │  A4988×2  │

  └────┬────┘                       └─────┬─────┘
       │ 5V                               │ 12V

## 详细接线表

### ESP32-S3 → A4988驱动器（X轴）
| ESP32引脚 | A4988引脚 | 说明 |
|---|---|---|
| GPIO13 | DIR | 方向控制 |
| GPIO14 | STEP | 脉冲信号 |
| GPIO15 | EN | 使能（低电平有效） |
| 5V | VDD | 逻辑电源 |
| GND | GND | 共地 |

### ESP32-S3 → A4988驱动器（Y轴）
| ESP32引脚 | A4988引脚 | 说明 |
|---|---|---|
| GPIO26 | DIR | 方向控制 |
| GPIO27 | STEP | 脉冲信号 |
| GPIO25 | EN | 使能 |
| 5V | VDD | 逻辑电源 |
| GND | GND | 共地 |

### A4988 → 步进电机
| A4988 | 电机 |
|---|---|
| VMOT | 12V电源正极 |
| GND (电机侧) | 12V电源负极 |
| 1A, 1B | 电机A相线圈 |
| 2A, 2B | 电机B相线圈 |

> ⚠️ A4988的VMOT和GND是电机电源侧，VDD和GND是逻辑侧，两侧GND必须共地！

### 电磁铁控制
| ESP32 | MOS管 | 电磁铁 | 12V电源 |
|---|---|---|---|
| GPIO32 | 栅极(G) | | |
| GND | 源极(S) | | GND |
| | 漏极(D) | 负极 | |
| | | 正极 | 正极 |

> ⚠️ 电磁铁是感性负载，必须在两端并联续流二极管（1N4007），阴极接正极！

### 限位开关
| ESP32 | 开关 |
|---|---|
| GPIO34 | X左限位（一端接GPIO，一端接GND） |
| GPIO35 | X右限位 |
| GPIO36 | Y前限位 |
| GPIO39 | Y后限位 |

> 使用内部上拉，开关按下时为低电平。

### 电源分配
```
12V 3A适配器
├── A4988 VMOT ×2（电机电源）
├── 电磁铁（经MOS管）
├── LED灯带（12V）
└── LM2596降压模块 → 5V
    ├── ESP32-S3（5V或USB供电）
    ├── A4988 VDD ×2
    ├── 蜂鸣器
    └── 霍尔传感器
```

## 注意事项

1. **共地**：所有模块的GND必须连在一起
2. **A4988电流调节**：通电后用螺丝刀调节电位器，测量VREF引脚电压，目标≈0.5V（对应电流≈1A）
3. **散热**：A4988必须装散热片，长时间运行可能需要小风扇
4. **接线顺序**：先接信号线，最后接12V电源；断电后再拆线
5. **首次测试**：先不接电机，用万用表测A4988输出端是否有脉冲
