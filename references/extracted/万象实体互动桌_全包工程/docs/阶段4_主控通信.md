# 阶段4：主控通信

## 目标
ESP32固件框架完善，网页控制端可通过BLE实时控制底座运动。

## 4.1 固件架构

### 任务划分（FreeRTOS）
```
┌─────────────────────────────────────┐
│              ESP32-S3               │
├──────────┬──────────┬───────────────┤
│ 核心0    │ 核心1    │               │
│ BLE任务  │ 电机任务  │  状态监控任务  │
│ 接收指令 │ 运动控制  │  限位/安全    │
│ 发送状态 │ 队列执行  │  电磁铁       │
└──────────┴──────────┴───────────────┘
```

### 代码结构
```
firmware/src/
├── main.cpp              ← 入口，初始化所有模块
├── config.h              ← 引脚定义、参数配置
├── motor_control.h/cpp   ← 步进电机控制（AccelStepper）
├── ble_service.h/cpp     ← BLE GATT服务
├── electromagnet.h/cpp   ← 电磁铁控制
├── limit_switch.h/cpp    ← 限位开关
└── command_parser.h/cpp  ← 指令解析
```

### 核心配置（config.h）

// 电机引脚

## 4.2 BLE协议

### 服务与特征
- 设备名：`WanxiangTable`
- Service: `FFE0`
- Characteristic: `FFE1`（可读可写可通知）

### 指令集
| 指令 | 格式 | 说明 |
|---|---|---|
| 移动 | `MOVE,X,200,Y,-100` | XY相对移动（步） |
| 移动到 | `GOTO,X,1000,Y,500` | 绝对移动到坐标 |
| 回零 | `HOME` | 两轴回零 |
| 电磁铁 | `MAG,ON` / `MAG,OFF` | 吸合/释放 |
| 状态查询 | `STATUS?` | 返回当前坐标 |
| 速度设置 | `SPEED,1500` | 设置最大速度 |
| 移动互动片 | `PIECE,FROM,3,2,TO,5,4` | 从格(3,2)移到(5,4) |

### 状态回传格式
```
OK,X:1200,Y:800,MAG:ON,READY
```

## 4.3 网页控制端

### 功能
- BLE扫描连接
- XY方向按键控制
- 速度滑块
- 电磁铁开关
- 坐标显示
- 回零按钮

### 使用方法
```bash
# 直接用Chrome打开
web/index.html
```
或启动本地服务器：
```bash
cd web
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

### 技术要点
- 使用 **Web Bluetooth API**（仅Chrome/Edge支持）
- 无需安装App，打开网页即用
- 代码在 `web/app.js`，注释详细

## 4.4 关键代码说明

### 电机控制（motor_control.cpp）
- 使用AccelStepper库，支持加减速
- 双轴同步运动（MultiStepper）
- 限位开关中断保护

### 指令解析（command_parser.cpp）
- 逗号分隔的文本协议
- 解析后放入FreeRTOS队列
- 电机任务从队列取指令执行

### 安全机制
- 限位开关触发立即停止
- 指令超时（5秒无指令）自动断电电机
- 电磁铁过热保护（连续吸合不超过30秒）
