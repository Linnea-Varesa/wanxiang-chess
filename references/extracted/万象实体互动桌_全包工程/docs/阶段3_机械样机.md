# 阶段3：机械样机

## 目标
完成XY移动机构、桌垫面板、互动片的制作和组装。

## 3.1 机械结构设计

## 3.2 3D打印件

需要打印的零件（STL文件需自行设计或参考开源）：
1. **电机支架×2** — 固定42步进电机
2. **电磁铁支架×1** — 安装在XY滑台上
3. **桌垫框架×1** — 支撑亚克力面板
4. **互动片外壳×若干** — 包裹亚克力圆片
5. **限位开关支架×4** — 固定微动开关

**打印参数**：
- 材料：PLA
- 层高：0.2mm
- 填充：20%
- 支撑：需要时开启

> 3D模型文件较大，本工程提供设计说明和关键尺寸，建议用Tinkercad/Fusion 360自行建模，或在淘宝搜索"3D打印服务"代打。

## 3.3 组装步骤

### Step 1：组装XY滑台
1. 将两根光轴/导轨固定在底座两侧
2. 安装X轴滑台和Y轴滑台
3. 固定步进电机，安装同步带和同步轮
4. 调整皮带张紧度（手指按压下沉5mm左右）

### Step 2：安装电磁铁
1. 将电磁铁固定在XY滑台的移动块上
2. 电磁铁顶面距亚克力面板底部≤2mm
3. 接线：12V经MOS管控制，并联续流二极管

### Step 3：安装限位开关
1. X轴左右各1个，Y轴前后各1个
2. 调整位置，确保滑台碰到时电机能停止
3. 接线：一端接GPIO，一端接GND（内部上拉）

### Step 4：制作互动片
1. 激光切割Φ25mm亚克力圆片
2. 底部粘贴Φ10mm钕铁硼磁铁
3. 顶部粘贴ArUco标记（打印后裁剪）
4. 可选：套3D打印外壳

### Step 5：总装
1. 将亚克力面板盖在框架上
2. 摄像头固定在正上方30cm处
3. 所有线缆整理固定，避免干涉运动

## 3.4 机械调试

### 皮带张紧
- 太松：丢步、定位不准
- 太紧：电机发热、噪音大
- 标准：用手拨动皮带，能转动约1/4圈

### 移动顺滑度
- 断电后用手推动滑台，全程无卡顿
- 如有卡顿，检查导轨平行度、螺丝松紧

### 定位精度校准
```bash
# 运行标定工具
python ../tools/calibration.py
# 按提示移动到各个角点，记录步距
# 校准后写入 firmware/src/config.h 的 STEPS_PER_MM
```
