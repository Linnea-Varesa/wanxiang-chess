# 阶段1：需求与方案

## 目标
明确产品规格，完成物料采购，搭建开发环境。

## 你要做什么

### 1.1 确定核心参数
| 参数 | 推荐值 | 说明 |
|---|---|---|
| 棋盘规格 | 8×8 | 格距30mm，总尺寸240×240mm |
| 互动片尺寸 | 直径25mm，厚3mm | 亚克力圆片+底部磁铁 |
| 移动机构 | XY同步带滑台 | 行程250×250mm |
| 识别方式 | 顶部摄像头+ArUco标记 | 固定俯拍，标记贴在互动片顶部 |
| 主控 | ESP32-S3 N16R8 | 16MB Flash + 8MB PSRAM |
| 通信 | BLE 5.0 | 手机/网页直连 |

### 1.2 采购物料
完整BOM见 `../hardware/BOM.csv`，关键件：
- ESP32-S3开发板 ×1
- 42步进电机 ×2
- A4988驱动 ×2
- 12V吸盘电磁铁 ×1
- USB摄像头 ×1
- 12V 3A电源 ×1
- 限位开关 ×4
- 杜邦线、面包板

**采购建议**：电子件在同一家店凑单（立创商城/优信电子），机械件另买。

### 1.3 搭建开发环境

#### 固件环境
```bash
# 1. 安装VS Code + PlatformIO插件
# 2. 用VS Code打开 firmware/ 目录
# 3. PlatformIO会自动安装ESP32平台和依赖库
# 4. 连接开发板，点Upload测试
```

#### Python环境
```bash
cd pc
pip install -r requirements.txt
# 验证
python -c "import cv2; print('OpenCV', cv2.__version__)"
```

#### 依赖库说明
- `opencv-python` — 摄像头+ArUco识别
- `numpy` — 矩阵运算
- `python-chess` — 国际象棋规则
- `pyserial` — 串口调试（可选）
