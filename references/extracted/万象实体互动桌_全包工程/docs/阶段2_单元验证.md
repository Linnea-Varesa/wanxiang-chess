# 阶段2：单元验证

## 目标
四个核心单元各自独立跑通：摄像头识别、电机控制、电磁铁、BLE通信。

## 单元1：摄像头ArUco识别

### 要干嘛
用顶部摄像头识别棋盘上每个互动片的位置和ID。

### 需要什么
- USB摄像头
- 打印好的ArUco标记（`tools/` 下有生成脚本）
- 电脑

### 代码
```bash
cd pc
python camera_recognition.py --camera 0 --show
```

### 原理
1. OpenCV捕获摄像头画面
2. 用`cv2.aruco`检测标记的四个角点
3. 根据角点中心计算棋盘格坐标
4. 输出：`{id: (row, col), ...}`

### 验证标准
- 固定光照下，8×8棋盘识别准确率≥95%
- 识别延迟<100ms

## 单元2：步进电机控制

### 要干嘛
ESP32通过A4988驱动42步进电机，实现XY两轴精确移动。

### 接线
| ESP32引脚 | A4988 | 说明 |
|---|---|---|
| GPIO13 | X_DIR | X轴方向 |
| GPIO14 | X_STEP | X轴脉冲 |
| GPIO15 | X_EN | X轴使能 |
| GPIO26 | Y_DIR | Y轴方向 |
| GPIO27 | Y_STEP | Y轴脉冲 |
| GPIO25 | Y_EN | Y轴使能 |
| 5V | VDD | 逻辑电源 |
| GND | GND | 共地 |
| 12V | VMOT | 电机电源 |

### 代码
固件中 `firmware/src/motor_control.cpp`，使用AccelStepper库。

### 串口命令
```
MOVE X 200    → X轴正转200步
MOVE Y -100   → Y轴反转100步
HOME          → 两轴回零（碰限位开关）
STATUS        → 查询当前位置
```

### 验证标准
- 移动100步误差≤1步
- 连续移动50次无丢步
- 回零重复精度≤0.5mm

---

## 单元3：电磁铁控制

### 要干嘛
通电吸合互动片，断电释放，实现"抓取-移动-放下"。

### 接线
| ESP32 | 元件 | 说明 |
|---|---|---|
| GPIO32 | MOS管栅极 | PWM控制（也可开关量） |
| 12V | 电磁铁正极 | 经MOS管控制 |
| GND | 电磁铁负极 | 共地 |

> 注意：电磁铁是感性负载，必须并联续流二极管！

### 代码
`firmware/src/electromagnet.cpp`

### 串口命令
```
MAG ON    → 吸合
MAG OFF   → 释放
MAG PULSE 500 → 吸合500ms后释放
```

### 验证标准
- 吸合响应<50ms
- 能稳定吸附带铁片的互动片
- 连续吸放100次无故障

## 单元4：BLE通信

### 要干嘛
ESP32作为BLE外设，手机/网页作为中心设备，收发控制指令。

### 协议设计
- Service UUID: `0000ffe0-0000-1000-8000-00805f9b34fb`
- Characteristic UUID: `0000ffe1-0000-1000-8000-00805f9b34fb`
- 波特率模拟：文本协议，每行一条指令

### 指令格式
```
MOVE,X,200          → 移动
MAG,ON              → 电磁铁
HOME                → 回零
STATUS?             → 查询状态
```

### 代码
`firmware/src/ble_service.cpp`

### 验证
用手机安装"nRF Connect"APP，扫描连接"WanxiangTable"，发指令测试。
