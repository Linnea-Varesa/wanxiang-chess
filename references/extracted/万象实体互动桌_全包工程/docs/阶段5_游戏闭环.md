## 5.1 五子棋

### 规则引擎（pc/gomoku/board.py）
- 15×15棋盘（也可配置为8×8）
- 黑白双方轮流落子
- 五子连珠获胜（横/竖/斜）
- 禁手规则可选（默认关闭）

### AI算法（pc/gomoku/ai.py）
- **Minimax + α-β剪枝**
- 搜索深度：3～4层（可配置）
- 评估函数：
  - 连五：100000分
  - 活四：10000分
  - 冲四：1000分
  - 活三：500分
  - 眠三：100分
  - 活二：50分
- 难度等级：简单(2层)/中等(3层)/困难(4层)

### 运行
```bash
cd pc
python -m gomoku.game --difficulty medium
```

### 与硬件联动
```
玩家落子 → 摄像头识别 → 更新棋盘 → AI计算 → 
发送移动指令 → ESP32电磁铁移动互动片 → 摄像头确认
```

### 关键代码
```python
# gomoku/ai.py 核心
def find_best_move(board, depth=3):
    best_score = -inf
    best_move = None
    for move in board.get_candidate_moves():
        board.make_move(move)
        score = -minimax(board, depth-1, -inf, inf)
        board.undo_move()
        if score > best_score:
            best_score = score
            best_move = move
    return best_move
```

## 5.2 国际象棋

### 规则引擎
使用 `python-chess` 库：
```python
import chess
board = chess.Board()
board.push_san("e4")  # 走e4
print(board.legal_moves)  # 合法走法
```

### AI引擎
集成 **Stockfish**（开源国际象棋引擎）：
```bash
# 安装Stockfish
# Ubuntu/Debian: sudo apt install stockfish
# Mac: brew install stockfish
# Windows: 下载 https://stockfishchess.org/download/
```

```python
import chess
import chess.engine

engine = chess.engine.SimpleEngine.popen_uci("/usr/games/stockfish")
result = engine.play(board, chess.engine.Limit(time=0.5))
board.push(result.move)
```

### 与硬件联动
国际象棋的移动较复杂（需要拿起被吃的子），首版简化：
- 只演示AI走一步（空目标格）
- 吃子场景用"推到旁边"代替
- 王车易位、吃过路兵暂不支持
