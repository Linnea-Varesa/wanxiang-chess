# 阶段6：内容包装

## 目标
制作一个主题皮肤（二次元/家庭陪伴），实现互动片外观和界面风格的可切换。

## 6.1 主题设计

### 主题结构
每个主题包含：
```
themes/
└── my_theme/
    ├── theme.json        ← 主题配置（名称、配色、描述）
    ├── pieces/           ← 互动片贴图
    │   ├── black.png
    │   ├── white.png
    │   └── special.png
    ├── ui/               ← 界面素材
    │   ├── background.png
    │   └── icons/
    └── sounds/           ← 语音提示（可选）
        ├── move.wav
        └── win.wav
```

### theme.json 示例
```json
{
  "name": "星空幻想",
  "version": "1.0",
  "author": "你的名字",
  "colors": {
    "primary": "#6C5CE7",
    "secondary": "#00CEC9",
    "background": "#0C0C1E",
    "text": "#FFFFFF"
  },
  "piece_style": "anime_character",
  "description": "二次元星空主题，互动片为角色徽章"
}
```

## 6.2 互动片制作

### 方法一：贴纸（最简单）
1. 设计角色图案（25×25mm）
2. 用A4纸打印，裁剪成圆片
3. 双面胶贴在亚克力互动片顶部
4. 注意：ArUco标记必须保留在中心！

### 方法二：3D打印外壳
1. 设计中空圆柱外壳（内径26mm）
2. 顶部嵌入角色卡片
3. 底部留磁铁槽
4. 打印后组装

### ArUco标记与角色图案共存
```
┌─────────────┐
│   角色图案    │  ← 外圈装饰
│  ┌───────┐  │
│  │ ArUco │  │  ← 中心标记（必须清晰）
│  │ 标记   │  │
│  └───────┘  │
└─────────────┘
```
> ArUco标记周围必须有白色边框，角色图案不能遮挡标记区域。

## 6.3 网页端主题切换

### 实现方式
- CSS变量控制配色
- JS加载theme.json切换样式
- 互动片预览图动态更换

### 代码位置
`web/app.js` 中的 `loadTheme(themeName)` 函数

### 使用
```javascript
// 切换主题
loadTheme('starry_sky');

// 可用主题
listThemes();  // ['default', 'starry_sky', 'forest']
```

## 6.4 推荐主题方向

| 主题 | 互动片风格 | 界面配色 | 适合场景 |
|---|---|---|---|
| 经典黑白 | 标准棋子 | 木纹+黑白 | 棋类演示 |
| 星空幻想 | 角色徽章 | 深紫+青色 | 二次元展示 |
| 森林冒险 | 动物棋子 | 绿色+棕色 | 亲子教育 |
| 赛博朋克 | 霓虹图标 | 黑色+霓虹 | 科技展示 |

## 6.5 语音提示（可选）

用ESP32的DAC或外接蜂鸣器播放简单提示音：
- 移动成功："嘀"
- 获胜：上升音阶
- 错误：下降音阶

代码：`firmware/src/buzzer.cpp`（如需要可自行添加）
