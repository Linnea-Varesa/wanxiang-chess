## 8.2 演示视频脚本（3分钟）

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0:00-0:20 | 产品全景+标题 | "这是万象实体互动桌，一个可更换互动片的桌面机器人平台" |
| 0:20-0:50 | 摄像头识别特写 | "顶部摄像头通过ArUco标记识别每枚互动片的位置和身份" |
| 0:50-1:30 | 五子棋对局过程 | "玩家落子后，AI自动计算，底座电磁铁吸附互动片移动" |
| 1:30-2:00 | 主题切换演示 | "互动片和界面可以切换主题，从经典棋类到二次元角色" |
| 2:00-2:30 | 机械结构特写 | "XY同步带滑台+单电磁铁，成本仅为多电机方案的1/5" |
| 2:30-3:00 | 成本表+总结 | "首版成本约800元，未来可扩展到教育、陪伴等多场景" |

**拍摄建议**：
- 用手机支架固定，俯拍+侧拍两个角度
- 光线充足，避免反光
- 录制前先彩排2次，确保一次成功
- 后期用剪映/CapCut加字幕和背景音乐

## 8.4 现场演示准备

### 演示流程（3分钟）
1. 开机，展示待机状态（10秒）
2. 启动五子棋，玩家落子（30秒）
3. AI自动移动互动片（30秒）
4. 切换主题，展示互动片更换（30秒）
5. 展示手机/网页控制端（30秒）
6. 总结产品特点（30秒）

### 应急预案
| 风险 | 应对 |
|---|---|
| 演示时移动卡滞 | 提前彩排5次以上，准备备用互动片 |
| 识别失败 | 准备手动模式，可跳过识别直接演示移动 |
| BLE连不上 | 准备串口控制作为兜底 |
| 时间不够 | 只演示五子棋+主题切换，跳过国际象棋 |
