# 阶段7：可靠性测试

## 目标
通过自动化测试验证系统稳定性，修复发现的问题。

## 7.1 测试项目与指标

| 测试项 | 指标 | 测试方法 |
|---|---|---|
| 互动片定位 | 准确率≥95% | 固定光照下，8×8棋盘逐格测试 |
| 身份识别 | 区分≥5种标记 | 5种ArUco ID各测20次 |
| 自动移动 | 成功率≥90% | 连续20次移动，统计成功次数 |
| BLE通信 | 延迟<300ms | 发指令到收到ACK的时间 |
| 断线重连 | 可自动恢复 | 断开蓝牙后10秒内重连 |
| 安全保护 | 限位立即停止 | 移动中触发限位开关 |
| 成本 | ≤1600元 | 实际采购金额统计 |

## 7.2 自动化测试脚本

### 移动可靠性测试
```bash
cd tools
python reliability_test.py --test movement --count 20
```
脚本会：
1. 发送移动指令到随机位置
2. 等待移动完成
3. 摄像头确认互动片是否到达
4. 记录成功/失败
5. 输出统计报告

### 识别准确率测试
```bash
python reliability_test.py --test recognition --count 100
```
脚本会：
1. 逐格放置互动片
2. 摄像头识别
3. 对比预期位置
4. 输出混淆矩阵

### BLE延迟测试
```bash
python reliability_test.py --test ble --count 50
```
脚本会：
1. 记录发送时间戳
2. 等待ESP32回传ACK
3. 计算延迟
4. 输出平均/最大/最小延迟

## 7.3 常见问题与修复

### 问题1：移动卡滞
**现象**：电机响但不动，或移动到一半停住
**原因**：
- 皮带太松/太紧
- A4988电流不够（调电位器）
- 机械干涉
**修复**：
- 调整皮带张紧度
- 用螺丝刀调A4988上的电位器（顺时针增大电流）
- 检查滑台是否有异物

### 问题2：识别误判
**现象**：互动片位置识别错误，或ID认错
**原因**：
- 光线不均匀/反光
- ArUco标记磨损
- 摄像头角度倾斜
**修复**：
- 加补光灯，确保均匀照明
- 重新打印标记，用透明胶带保护
- 调整摄像头为正俯视，运行标定

### 问题3：电磁铁吸力不足
**现象**：移动时互动片脱落
**原因**：
- 电磁铁距互动片太远
- 互动片底部无铁片
- 电压不足
**修复**：
- 调整电磁铁高度，距面板底部≤1mm
- 互动片底部贴薄铁片（或用磁铁异极相吸）
- 确保12V供电，线径足够

### 问题4：BLE断连
**现象**：控制过程中突然断开
**原因**：
- 距离太远（>5米）
- 干扰多（2.4G Wi-Fi拥堵）
- 固件看门狗复位
**修复**：
- 缩短距离，减少遮挡
- 切换BLE信道（固件中可配）
- 检查ESP32是否过热/供电不足
