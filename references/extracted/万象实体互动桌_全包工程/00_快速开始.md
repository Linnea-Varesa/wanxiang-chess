# 快速开始指南（新手必读）

## 你需要准备什么

### 硬件（按优先级）
1. **ESP32-S3开发板**（N16R8，约20元）—— 大脑
2. **42步进电机×2 + A4988驱动×2**（约50元）—— 运动
3. **USB摄像头**（约20元）—— 眼睛
4. **直流吸盘电磁铁12V**（约12元）—— 手
5. **12V 3A电源适配器**（约20元）—— 能量
6. **面包板+杜邦线**（约15元）—— 接线
7. **电脑**（Windows/Mac/Linux均可）

> 第一阶段不需要机械结构，用面包板+电机就能跑通全部软件逻辑。

### 软件
- **VS Code** + **PlatformIO插件**（写固件）
- **Python 3.9+**（跑识别和AI）
- **Chrome或Edge浏览器**（网页控制端，需要支持Web Bluetooth）

## 第一步：搭环境（30分钟）

### 1. 安装VS Code和PlatformIO
```
1. 下载安装 VS Code: https://code.visualstudio.com/
2. 打开VS Code，左侧扩展商店搜索 "PlatformIO IDE"，安装
3. 等待PlatformIO初始化完成（首次较慢）
```

### 2. 安装Python依赖
```bash
# 进入pc目录
cd pc

# 安装依赖
pip install -r requirements.txt
```

### 3. 测试摄像头
```bash
python test_scripts/test_camera.py
```
能看到画面弹出就说明摄像头OK。

## 第二步：跑通第一个Demo（1小时）

### 1. 编译烧录固件
```bash
# 用VS Code打开 firmware 目录
# 连接ESP32-S3到电脑
# 点击PlatformIO底部栏的 "Upload" 按钮（→）
# 等待编译+烧录完成
```

### 2. 测试电机
```bash
# 打开串口监视器（PlatformIO底部栏的插头图标）
# 波特率 115200
# 输入命令:
#   MOVE X 100    → X轴移动100步
#   MOVE Y 50     → Y轴移动50步
#   HOME          → 回零
#   MAG ON        → 电磁铁吸合
#   MAG OFF       → 电磁铁释放
```

### 3. 打开网页控制端
```
用Chrome打开 web/index.html
点击"连接设备"，选择 "WanxiangTable"
拖动滑块控制XY移动
```

## 常见问题

**Q: 电机不动怎么办？**
A: 检查A4988的VMOT是否接12V，逻辑电压是否接5V，DIR/STEP引脚是否接对。

**Q: 摄像头识别不到ArUco标记？**
A: 确保标记打印清晰、光线充足、标记在画面中央。先运行 `test_camera.py` 调试。

**Q: BLE连不上？**
A: 必须用Chrome/Edge，且系统蓝牙已开启。ESP32固件已烧录并上电。

**Q: 电磁铁吸力不够？**
A: 确保用12V供电（不要用5V），互动片底部贴铁片或磁铁。
