# 07 固件开发计划

## V1 固件职责

- 设备启动、自检、心跳和版本报告。
- 识别接口轮询或事件接收（具体传感器由实验结果决定）。
- 事件去抖、快照上传和错误码。
- BLE GATT 或串口传输，复用统一协议。
- 音频触发接口、按键和状态灯。
- 保留运动控制接口，但 V1 默认禁止未经回零的绝对运动。

## V1.5 运动职责

- X/Y 步进脉冲、方向、使能和速度限制。
- 上电回零、软件边界、硬限位和超时。
- 电磁铁吸合/释放、连续通电保护和温升记录。
- STOP 可中断当前动作并释放磁铁。
- 运动完成必须返回命令 ID 和位置复核结果。

## 历史工程接手项

交接资料指出历史固件存在参数解析索引风险、命令格式不一致、PIECE 硬编码下标、缺少软件限位和回零超时。新实现应写独立解析函数和测试，不直接复制旧代码。

## 固件测试用例

```text
MOVE,X,200,Y,-100
GRID,ROW,3,COL,4
GOTO,X,1000,Y,500
MOTION,FROM,e2,TO,e4,CMD,44
STOP,CMD,45
```

测试范围包括：缺字段、非数字、负值、越界、未回零、限位触发、重复命令、超时、断线、STOP 和重新连接后的状态报告。

## 安全原则

上电自检失败时禁止动作；回零限位未确认时禁止绝对运动；任何超时、过流、限位或位置复核失败都进入 `PAUSED`；恢复前要求重新快照，不自动执行旧队列。
