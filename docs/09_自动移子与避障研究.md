# 09 自动移子与避障研究

## 物理动作与逻辑走法分离

国际象棋逻辑上允许马跳过棋子，但平面磁吸机构不能穿过实体棋子。运动层必须保存临时停车、磁头位置、吸附状态和复核结果；逻辑层只有在整组物理动作完成后才提交走法。

## 首选验证结构

桌下单 XY 滑台 + 单个可控电磁铁。先验证单子吸附、直线移动、释放、落位和再次识别。两个电机轴可以由一块 MCU 控制；增加 MCU 不会自动增加独立搬运能力。

## 让路动作

```text
规划目标走法
→ 检查磁头路径和棋子间隙
→ 若被挡，选择临时停车位
→ 搬开挡路棋子并复核
→ 搬运目标棋子并复核
→ 恢复挡路棋子并复核
→ 提交逻辑走法
```

临时停车区应在棋盘外或预留安全格，不能让被搬开的兵被规则层误认为已走一步。目标棋子被吃时，需先把被吃子移到收纳区，再搬主动子。

## 必测局面

- 开局密集摆放，马从 b1/g1 出位。
- 目标格有棋子，需要吃子。
- 王车易位的两枚棋子顺序动作。
- 升变时棋子替换或角色更新。
- 多个临时停车位同时占用。
- 人工取走磁头或棋子后 STOP、重同步和恢复。

## 多执行器阶段门

只有满足以下任一条件才进入双磁头研究：单磁头完成率无法达到验收目标；顺序让路耗时明显影响体验；用户明确要求同步视觉效果。研究内容包括空间调度、磁场串扰、碰撞、共享路径、独立到位检测和成本，不以“多控制模块”作为方案目标。
