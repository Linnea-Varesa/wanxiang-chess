# 17 开发板选择与系统分层

## 当前推荐组合

> **路线更新（2026-09-18）**：ESP32-S3 仍作为主控，但感知主链路不再默认使用 DS2431 触点。当前先验证被动 NFC/磁编码与静态位置层；DS2431/74HC4067 留作电气基线，自动移子顺延。详细取舍见 [`19_无触点身份与自行移动路线评估.md`](19_无触点身份与自行移动路线评估.md)。

### 棋盘主控：ESP32-S3-DevKitC-1-N8R8

首批建议购买 2 块同型号开发板，1 块主用、1 块备份。选择理由：

- 原生 BLE 5，直接满足 Android 通信，不需要额外蓝牙模块；
- 3.3 V GPIO，适合 DS2431/DS2401、74HC4067、霍尔传感器和状态灯；
- USB 下载和串口调试方便，适合当前两人学习开发；
- 8 MB Flash/8 MB PSRAM 版本给日志、协议和后续音频接口留余量；
- 当前仓库已有 PlatformIO 工程目标 `esp32-s3-devkitc-1`，迁移成本低。

这块开发板是“棋盘主控”，不是 AI 主机。ESP32-S3 负责读头/传感器扫描、磁力运动状态机、屏幕和 BLE；AI 先在调试端或后续微信小程序/Android 端运行。

`N8R8` 是优先选项，不是必须条件；识别固件本身不需要 PSRAM。如果实际购买的开发板是 N8、N4、WROOM-1 或其他 ESP32-S3 板，必须先记录准确丝印、Flash/PSRAM 型号和引脚图，再修改 [`firmware/src/config.h`](../firmware/src/config.h) 与 [`hardware/pinouts/主控引脚表.md`](../hardware/pinouts/主控引脚表.md)。

### 不建议首批使用的主控

- **ESP32-C3**：BLE 足够，但 GPIO 和资源余量较小；只有预算非常紧或已有现货才考虑。
- **ESP32-WROOM-32**：BLE 可用，但当前仓库和后续资源优先按 S3 维护；不为换板增加变量。
- **树莓派/国产 Linux 板**：对 1-Wire 和 BLE 不是不能做，但会增加系统、存储、启动和供电复杂度；AI 放在 Android，暂不需要。
- **Arduino Uno/ESP8266**：不适合作为 Android BLE 主控。

## 主控分工

首版不要拆成多个控制模块。一个 ESP32-S3 足以负责：

1. 触点扫描和 DS2431/DS2401 ROM 读取；
2. 识别去抖、快照和错误状态；
3. BLE GATT 服务；
4. 后续单 XY 电机/电磁铁的运动接口。

只有在 8×8 扫描周期、运动实时性或隔离测试证明一个主控不够时，才考虑把运动控制拆成第二块 MCU。多个模块不会自动解决“多个棋子同时移动”的机械问题。

## 识别接口建议

- 当前主线：下方移动读头读取被动 `NTAG213` UID，滑台坐标提供格位；首轮只做 2×2。
- 备选主线：每格磁传感器读取磁编码；驱动磁场关闭后再采样。
- 电气基线：1 个 `74HC4067` + DS2431/DS2401 触点实验，不作为自行移动产品默认表面接口。

- NFC 读头：首轮使用 1 个带 I2C/SPI 的 PN532 类模块和小尺寸外部线圈做读距实验；最终读头型号在 2×2 读距数据后确定；
- 运动接口：首轮只记录未来磁力耦合件的尺寸、电源和状态字段，不采购滑台；
- 电气基线：1 个 74HC4067 做 4×4 触点实验；不先扩展 64 格；
- 屏幕：预留 SPI 总线给 2.8 inch ILI9341，实际 GPIO 等开发板到手后核对；
- 协议：复用 [`software/protocol/message_schema.md`](../software/protocol/message_schema.md) 和 [`software/protocol/test_vectors.md`](../software/protocol/test_vectors.md)。

## 需要立即修正的工程认识

`DS2431G/GA` 是“唯一 ID + 小容量 EEPROM”器件，适合把初始棋子信息预写到棋子中；`DS2401+` 只有工厂 UID，保留为电气原型备选。无论使用哪一种，Android 都要维护 UID、角色和对局状态的独立数据。

## 开发板采购判定

采购页面必须同时满足：

- 芯片确实为 ESP32-S3，而不是 ESP32-C3/ESP32；
- 板载 USB 可下载和串口日志；
- 引出 GPIO5–10 或有等价可用引脚；
- 3.3 V、GND、5 V/VBUS 标注明确；
- 标出 Flash/PSRAM 配置；
- 有可核对的板卡原理图或引脚图。

如果商品只写“ESP32-S3 开发板”而没有具体模组和引脚图，不作为首选采购。
