# 无触点身份与棋子自行移动路线评估

> 本文讨论的是项目后续创新方向。2026 年只执行静态身份/格位识别与软件闭环，自动移子不作为今年验收项。

**时间 tag：`2026-09-18T18:30+08:00`**  
**决策编号：`D-2026-09-18-MOVE-01`**

## 结论

如果项目的核心创新是棋子在棋盘上自行移动，棋盘表面不应默认采用凸起弹簧针或镀金触点。原触点方案保留为低风险电气基线和故障对照，不再作为自行移动产品的主感知架构。

推荐主路线改为：

```text
棋子底部：被动身份标签 + 磁力耦合件
        ↓ 无接触读取
光滑、非金属棋盘面
        ↓
棋盘下方 XY 磁力驱动/扫描滑台（后续研究）
        ↓
磁力搬运棋子，扫描位置并复核身份
```

这里的“自行移动”指棋子不被机械夹爪抓取，棋盘下方的磁场或磁性滑台驱动棋子在表面移动。棋子仍然可以不带电池；运动能量由棋盘下方机构提供。

## 触点方案原本有什么价值

触点不是没有用，它解决的是三个工程问题：

1. 通过棋盘给无电池芯片供电；
2. 用 1-Wire 直接读取每枚棋子的唯一 UID；
3. 棋子落位后可以用电气读回确认“确实在这一格”。

所以触点很适合“静止棋子、玩家手动移子、低成本验证”的第一版电气原型。但它不等于完整的自行移动方案。

## 为什么触点会限制自行移动

- 凸起触点会增加滑动阻力，磁力不足时棋子可能卡在触点边缘；
- 棋子经过触点时会磨损、刮擦或改变接触压力；
- 触点要求棋子最后垂直落位，磁力平移不能只靠 XY 坐标完成；
- 触点区域要在棋子底部预留两个导电面，会限制底部磁体、标签和底座结构；
- 触点氧化、灰尘和轻微偏心会造成漏读，运动状态下更难判定是机械问题还是识别问题；
- 若改成抬起后搬运再放下，核心机构就变成夹具/磁吸搬运，而不是棋子在平面上自行移动。

## 新主路线的身份与定位分层

### A 方案：被动 NFC/13.56 MHz 标签 + 下方移动读头

棋子底部放置一个小尺寸 `NTAG213` 或同类 ISO14443A 被动标签；棋盘下方的 XY 滑台同时携带磁力驱动件和 NFC 读头线圈。滑台扫描某个格中心时读取标签 UID，格位由滑台坐标确定，身份由 UID 确定。

优点：棋子无需电池；棋盘表面可以完全平滑；标签 UID 可直接作为棋子身份；与后续磁力移动的结构方向一致。

风险：13.56 MHz 线圈尺寸、棋盘厚度、磁体和金属件会影响读距；一个固定读头不能同时知道 64 格所有棋子，因此需要下方读头扫描或每格天线阵列。首轮只做 2×2，不购买 64 格 RFID 阵列。

### B 方案：被动磁编码 + 磁传感器阵列

棋子底部放置多个小磁体或磁性编码片，棋盘每格用磁传感器读取磁场签名。它更贴合磁力驱动，但驱动磁场可能使传感器饱和，必须在“驱动磁场关闭后”再识别；32 枚棋子需要足够多的可区分编码，不能只放一个磁铁。

首轮只做单枚、三种编码的磁场实验，不直接承诺 64 格量产。`DRV5033` 只能检测有无磁体，不能单独识别棋子身份。

### C 方案：1-Wire 触点作为备选

`DS2431G/GA + 触点` 保留在独立实验夹具和低成本人工版中。如果无触点路线在棋盘厚度、读距或磁干扰上失败，仍可用它快速完成“识别和软件闭环”，但不把它表述成最终自行移动结构。

## 3D 打印验证顺序

1. 先按 [`../chess.3mf`](../chess.3mf) 原尺寸打印兵、马、车各 1–2 枚，测量底座直径、底面平整度、内部空间和棋盘格间隙。
2. 在同一底座上做三种可拆身份盘：空白盘、`NTAG213` 标签盘、磁编码盘；不要一开始打印 32 枚。
3. 用一枚 `6 mm × 2 mm` 的 `NdFeB N35/N42` 圆片做磁力耦合候选，先测试吸附力和 NFC 读距，再决定是否扩大直径或增加厚度。
4. 用一块约 3 mm 厚的非金属平板做 2×2 位置样片，逐格测试读头是否串读相邻格。
5. 只有身份读取、相邻格隔离和静态定位都通过后，才冻结棋盘模型；磁力移动另立后续阶段。

## 年底前的新阶段门

- `M0`：打印样品尺寸确认，标签/磁体能放入底部且不影响落位；
- `M1`：单枚标签在 2–3 mm 非金属板下可重复读取；
- `M2`：2×2 位置读取能区分四个格，不出现相邻格串读；
- `M3`（后续）：棋盘下方磁力驱动能移动一枚棋子，停下后读头能复核 UID；
- 未通过 `M1/M2` 时，不采购 64 格读头、整盘 PCB 或运动机构；回退到触点电气基线或重新调整标签/线圈。

## 对采购的直接影响

暂缓批量购买 `DS2431`、`74HC4067`、40 个弹簧针和 4×4 触点底板。优先采购少量 3D 打印耗材、13.56 MHz 被动标签、小型 NFC 读头/线圈和磁力耦合样件。ESP32-S3 仍保留，既可连接 NFC 读头，也可驱动后续磁力机构。
