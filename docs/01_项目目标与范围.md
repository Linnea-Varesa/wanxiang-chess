# 01 项目目标与范围

## 项目目标

在 12 个月内完成一台 8×8 国际象棋实体互动桌：棋盘能够识别带唯一身份的棋子及其格位，把局面同步到 Android，调用可调难度的国际象棋引擎，使用扬声器指导玩家落子，并在玩家操作后核对实体局面。自动移动作为独立后续能力接入，不得破坏首版语音指导闭环。

当前三个月优先验证无视觉、无触点身份主线：棋子底部优先采用无需电池的 NTAG213 等被动标签，先做 2×2、争取 4×4 的身份与格位联合识别；DS2431G/GA 与触点只作静止电气回退。芯片身份、预写角色和对局中的当前角色分开管理。三个月版本的具体边界见 [`13_三个月无视觉身份棋盘方案.md`](13_三个月无视觉身份棋盘方案.md)。

## 已确认约束

| 项目 | 决策 |
|---|---|
| 首发棋类 | 国际象棋，标准规则 |
| 目标用户 | 先个人使用，稳定后再评估小规模量产 |
| 团队 | 2 人，每人每周约 6 小时，合计约 12 人时 |
| 首批预算 | 2000–3000 元，按实验结果分批追加 |
| APP | Android 优先 |
| AI | 先评估 Android 本地运行；联网只作为后备，不作为首版依赖 |
| 已有工具 | 万用表、焊接工具、可调电源、基础机械工具 |
| 多棋子运动 | 2026 年不做；只记录接口和后续研究问题 |

## 首年必须交付

- 32 枚棋子具有唯一身份，并与棋种、阵营、当前角色分开建模；首轮只用少量样品完成标签和定位验证。
- 识别棋子当前所在的格位；2026 年验收 2×2，争取 4×4，不承诺 64 格最终阵列。
- 完整国际象棋规则：合法走法、将军、将死、和棋、易位、吃过路兵、升变、悔棋和重新摆局。
- BLE 设备连接、状态快照、递增版本、断线重连和 Android 棋盘显示。
- Android 难度设置、对局记录和 AI 走法显示。
- 语音播报建议走法、错误位置和等待确认。
- 玩家完成手动落子后，系统再次识别并确认；不能只因发出提示就提交走法。
- 自动移动不属于 2026 年交付；仅保留机械接口、状态字段和下一年度实验建议。

## 明确不纳入首年硬性范围

- 语音识别、唤醒词、自然语言聊天和棋局长篇讲解。
- 账号、云端记忆、远程联机、支付和商业内容授权。
- 多个棋子真正同时物理搬运。
- 可直接量产的外观、模具和完整认证。
- 其他棋类、教育包和角色互动内容。

## 版本定义

| 版本 | 目标 |
|---|---|
| V0 | 传感器/识别/规则/协议的台架实验，不承诺完整棋盘 |
| V1 | 语音指导版：玩家手动移动，Android 本地 AI，BLE 同步 |
| V1.5 | 后续研究：单 XY 磁头自动移动和顺序让路实验 |
| V2 | 根据实测需求决定双磁头、多执行器、联网或棋盘内置算力 |
