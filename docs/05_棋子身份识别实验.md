# 05 棋子身份识别实验

> 方向更新：三个月版本不采用摄像头识别。主实验是“棋子底部被动标签 + 无触点格位联合识别”；DS2431/触点只保留为静止电气回退。

身份器件封装、触点和后续自动移子约束见 [`docs/16_触点对自动移子影响与身份器件决策.md`](16_触点对自动移子影响与身份器件决策.md)；实验接线见 [`experiments/identity_2x2/实验方案.md`](../experiments/identity_2x2/实验方案.md)。

## 核心判断

棋子 UID 只回答“是哪一枚棋子”，不能单独回答“在哪个格”。必须验证 UID 与 8×8 格位的联合识别。身份标签、磁体、铁片、面板厚度、铜层和相邻天线会互相影响。

## 推荐路线

> **路线更新（2026-09-18）**：本文件的 DS2431/触点实验保留为电气基线。当前首轮改为使用 [`../mechanical/pieces/3mf模型核验_2026-09-18.md`](../mechanical/pieces/3mf模型核验_2026-09-18.md) 中的 3D 打印兵、马、车，测试 NTAG213 被动标签、磁编码盘和 2×2 无触点读距；不要在无触点数据通过前设计 8×8 固定 PCB。

DS2431 的 ROM 提供唯一身份，EEPROM 可保存初始信息；UID、EEPROM 字段、角色和升变状态仍由 Android 本地数据库分开管理。DS2401 只提供 UID。

## 实验分级

### E05-1 单子材料和标签测试

记录标签型号、UID、标签位置、旋转角度、偏心量、底板材料、面板厚度、读时长、漏读和误读；触点形状和弹簧针压力只在回退实验中记录。

### E05-2 2×2/4×4 联合定位

覆盖空位、相邻棋子、偏心、旋转、放置后稳定、多个棋子同时摆放和不同角色底座。输出每格的 ID、空位和置信度；位置必须来自校准的读头坐标、每格传感器或天线，不能把 UID 当作格位。

### E05-3 连续性与故障

连续扫描至少 100 次，统计每格成功率、邻位串读、单次扫描时间、整阵列周期、重试后成功率。任何“读到 UID 但坐标不确定”的结果都算失败。

### E05-4 后续扩展到 8×8

先做一个 4×4 分区，再评估全盘。记录线圈/读头互扰、扫描周期、布线和维护成本。2026 年不把 8×8 作为阶段门，全盘通过条件应包括识别结果可复现，而非只展示一次成功。

## 数据模型

```json
{
  "uid": "piece-017",
  "side": "white",
  "role": "pawn",
  "square": "e2",
  "confidence": 0.98,
  "observed_at": "2026-09-09T00:00:00Z"
}
```

`uid`、`role`、`square` 分开存储。升变时角色变化；备用棋子或替换棋子不能复用“UID 永久等于兵”的假设。

## 通过条件

- 至少 2×2 规模下能同时正确关联 ID 与格位，并记录是否具备扩展 4×4 的条件。
- 空位、邻位、偏心、旋转、抬起、放下均有定义行为。
- 对连续扫描、错误 ID、读不到和冲突有重试或暂停策略。
- 使用未来平滑棋盘和可拆底盖的材料做测试，避免后期返工；自动移子不作为本阶段验收项。
