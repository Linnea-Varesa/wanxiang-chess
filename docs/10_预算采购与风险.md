# 10 预算、采购与风险

## 三个月采购决策

三个月主线改为无视觉身份棋盘：ESP32-S3 + DS2401 一线制唯一 ID + 触点格位 + 74HC4067 + BLE。PN532/NTAG213 不作为主链路，64 格 RFID、摄像头、自动移子器件均后置。

## 首批预算分配

已有基本仪器，不重复采购。2000–3000 元先用于能否行通的实验，不用于一次性购买整套全盘零件。

| 类别 | 预算 |
|---|---:|
| ESP32-S3 开发板、稳压、连接器和线材 | 250–350 元 |
| DS2401、触点、多路器和小面积电路实验 | 350–650 元 |
| 棋子底座、磁体、面板和结构样片 | 200–350 元 |
| 小面积 PCB、打样和耗材 | 250–450 元 |
| 扬声器、功放和音频件 | 100–200 元 |
| 霍尔辅助、指示灯和调试备件 | 100–250 元 |
| 返工与追加实验预留 | 400–600 元 |
| 合计 | 1630–2750 元 |

若识别实验失败，停止扩大全盘采购，先切换后备路线。采购分三批：识别样片、通信/规则闭环、结构与运动件。

## 风险登记

| 风险 | 等级 | 触发条件 | 应对 |
|---|---:|---|---|
| UID 能读但格位不确定 | P0 | 单读头盘点无法定位 | 使用逐格触点；2×2/4×4 失败则停止扩展 |
| 触点接触不稳定 | P0 | 偏心、旋转或氧化导致漏读 | 环形触点、机械定位圈、重试和 UNSTABLE 状态 |
| 1-Wire 多路器时序异常 | P0 | 导通电阻/寄生电容导致 CRC 失败 | 缩短线长、调整上拉、先做单路和 4×4 波形测试 |
| 两人实际人时不足 | P0 | 连续两周无可检查输出 | 缩减自动移动，保住 V1 |
| 手机 AI 性能不足 | P1 | 思考时间过长/耗电 | 调低预算，转可选联网或运算板 |
| BLE 断线造成状态错乱 | P1 | 增量事件丢失 | 版本号、完整快照和重同步 |
| 机械让路失败 | P0 | 路径穿不过密集棋子 | 临时停车、绕行、顺序执行 |
| 固件限位失效 | P0 | 回零不停止或撞击 | 硬限位、超时、限流、STOP |
| 量产成本超标 | P2 | BOM 超预算或装配复杂 | 先完成个人样机，再做可制造性评估 |

## 量产前不得提前承诺

全盘识别成本、稳定移动寿命、噪声、温升、跌落/运输、EMC、材料安全和许可证义务都没有数据前，不能承诺固定售价或量产时间。
