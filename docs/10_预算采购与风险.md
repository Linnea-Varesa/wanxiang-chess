# 10 预算、采购与风险

## 三个月采购决策

三个月主线更新为无视觉、无触点静态识别验证：ESP32-S3 + 被动 NTAG213/磁编码候选 + 小型读头/位置层 + BLE。DS2431G/GA + 触点降为静止棋子电气基线；64 格 RFID、摄像头、整盘 PCB 和自动移子均后置。

## 首批预算分配

已有基本仪器，不重复采购。2000–3000 元先用于能否行通的实验，不用于一次性购买整套全盘零件。首批不把最终 32 枚棋子、标签或运动件全部买齐，先用样品验证尺寸、读距、串读和静态定位。

| 类别 | 预算 |
|---|---:|
| ESP32-S3 开发板、稳压、连接器和线材 | 250–350 元 |
| 打印棋子、被动标签、NFC 读头和磁体样片 | 300–650 元 |
| 2×2 平滑样片、结构件和小面积电路实验 | 200–400 元 |
| 小面积 PCB、打样和耗材 | 250–450 元 |
| 扬声器、功放和音频件 | 100–200 元 |
| 屏幕、调试备件和后置传感器 | 100–250 元 |
| 返工与追加实验预留 | 400–600 元 |
| 合计 | 1630–2750 元 |

若识别实验失败，停止扩大全盘采购，先切换后备路线。采购分三批：识别样片、通信/规则闭环、结构与运动件。

## 风险登记

| 风险 | 等级 | 触发条件 | 应对 |
|---|---:|---|---|
| UID 能读但格位不确定 | P0 | 单读头盘点无法定位 | 用滑台坐标或 2×2 读头隔离；失败则保留触点基线 |
| 标签读距不足/相邻格串读 | P0 | 3 mm 板下读不到或同时读到邻格 | 调整线圈、标签尺寸、棋盘厚度和扫描时序 |
| 未来磁力机构与身份件互扰 | P1 | 磁体使 NFC 失谐或传感器饱和 | 今年只做少量材料对照，后续分离驱动/读取时刻 |
| 两人实际人时不足 | P0 | 连续两周无可检查输出 | 缩减 4×4 和前端范围，保住静态 V1 |
| 手机 AI 性能不足 | P1 | 思考时间过长/耗电 | 调低预算，转可选联网或运算板 |
| BLE 断线造成状态错乱 | P1 | 增量事件丢失 | 版本号、完整快照和重同步 |
| 机械让路失败 | P0 | 路径穿不过密集棋子 | 临时停车、绕行、顺序执行 |
| 固件限位失效 | P0 | 回零不停止或撞击 | 硬限位、超时、限流、STOP |
| 量产成本超标 | P2 | BOM 超预算或装配复杂 | 先完成个人样机，再做可制造性评估 |

## 量产前不得提前承诺

全盘识别成本、稳定移动寿命、噪声、温升、跌落/运输、EMC、材料安全和许可证义务都没有数据前，不能承诺固定售价或量产时间。
