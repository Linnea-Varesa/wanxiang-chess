# 万象实体互动桌：国际象棋路线

本目录是新方向的正式工程目录。目标是用一年时间，由两人小组（每人每周约 6 小时）完成一台个人可稳定使用的国际象棋实体互动桌，并在稳定性、成本和安全性达到要求后评估小规模量产。

## 当前冻结的首年范围

- 国际象棋，8×8 棋盘，Android 优先。
- 首版先完成：棋子唯一身份、格位识别、棋局状态、BLE 同步、Android 记录和难度设置、AI 走法、语音指导。
- 玩家在首版手动移动棋子；系统识别并确认结果。
- 自动移动先做单棋子和顺序让路验证。多棋子物理同步移动不是首年硬性承诺。
- AI 首版优先在 Android 手机本地运行；必要时再使用联网服务或棋盘内置运算板。
- 首批实验预算约 2000–3000 元。已有万用表、焊接工具、可调电源和基础机械工具，不重复采购。

## 资料边界

`references/original_handoff/` 和 `references/original_archive/` 是历史交接资料和原始压缩包的只读参考副本。原工程第一版以五子棋、摄像头 ArUco 和单 XY 演示为主；新工程以本 README 和 `docs/` 中的决策为准。

## 先做什么

1. 用最终棋子底座、标签、磁体和面板材料完成 2×2/3×3 身份与位置识别实验。
2. 同步搭建 Android/PC 规则模拟器和 BLE 协议，不等待全盘硬件。
3. 形成“识别 → 合法走法 → AI → 语音 → 玩家落子确认”的闭环。
4. 识别闭环稳定后，再做全盘电路和单 XY 运动样机。
