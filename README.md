# 万象实体互动桌：国际象棋路线

当前版本正在从“触点身份棋盘”调整为“无触点静态识别优先”的原型：棋子底部优先测试无电池被动身份标签，棋盘表面保持平滑，通过小规模样片验证身份和格位。ESP32-S3 负责设备控制、快照、屏幕和通信，手机或后续微信小程序负责棋局、合法性、本地 AI 和语音指导。DS2431G/GA + 触点保留为电气基线和备用路线。自动移子只预留接口，今年不做实物交付。

摄像头识别、64 格 RFID 阵列、自动移子和量产结构不属于当前验收范围。

本目录是新方向的正式工程目录。目标是用一年时间，由两人小组（每人每周约 6 小时）完成一台个人可稳定使用的国际象棋实体互动桌，并在稳定性、成本和安全性达到要求后评估小规模量产。

## 当前冻结的首年范围

- 国际象棋，8×8 棋盘，Android 优先。
- 首版先完成：棋子唯一身份、静态格位识别、平滑棋盘、棋局状态、BLE 同步、AI 走法和语音/屏幕提示。
- 先用玩家手动放置验证识别；系统必须能用 UID 和格位复核结果。
- 自动移动、让路和多棋子同步只保留机械接口与研究记录，不列入 2026 年交付。
- Android 仅作为当前工程调试端；微信小程序保留为后期交互候选，协议不绑定某一种前端。
- 首批实验预算约 2000–3000 元。已有万用表、焊接工具、可调电源和基础机械工具，不重复采购。

## 先做什么

1. 根据 [`mechanical/pieces/3mf模型核验_2026-09-18.md`](mechanical/pieces/3mf模型核验_2026-09-18.md) 先打印少量兵、马、车，测量底座和身份盘空间。
2. 用被动 NFC/磁编码候选和 2×2 无触点样片验证身份、相邻格隔离和读距。
3. 同步搭建与前端无关的规则模拟器和 BLE 协议，不等待全盘硬件。
4. 形成“识别 → 合法走法 → AI → 语音/屏幕 → 玩家手动移动 → 复核”的闭环。
5. 识别稳定后，再为后续自动移子保留机械和通信接口，不在今年采购完整运动机构。
